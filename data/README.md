# data/

Figure-input tables (every figure and statistic is built from these):
- `editing_by_rep.csv`   — per-replicate raw editing, matched no-guide baseline, net, coverage.
- `bystander_by_rep.csv` — amplicon-wide adenosine scan, per condition per replicate.
- `runs.csv`             — sequencing-run manifest (see DATA_DICTIONARY.md for columns).
